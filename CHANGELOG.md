# Changelog

## 1.0.0 — 2026-10-17

- Modules 1–2: establish the Node.js/TypeScript MCP monorepo, mock-first adapters, shared household/event schemas, and sourced region-pack structure.
- Module 3: add household memory, storage repositories, DynamoDB support, and seeded India/US households.
- Module 4: add history-first predictions, regional scheduling rules, and reminder jobs.
- Module 5: add safety-gated diagnosis, evidence/citation handling, Bedrock ranking, and resolution logging.
- Module 6: add signed phone handoffs, messaging adapters, and EventBridge Scheduler to SQS.
- Module 7: add the shared mobile fix/booking experience, phone chat, localization starters, and MCP App renderer.
- Module 8: add a real Streamable HTTP simulator with deterministic and optional Bedrock routing, browser voice input, cards, and presenter rehearsal tools.
- Module 9: add privacy inventory, consent history, confirmed erasure, export, retention, redaction, and optional OAuth resource protection.
- Module 10: add scripted presenter mode, headless demo verification, preflight, benchmark, pack review tooling, container/deployment preparation, schema extraction, and submission drafts.

The workspace release version is 1.0.0. The monorepo schema remains independently versioned at 1.7.0; the first standalone `home-event-schema` extraction is versioned 1.0.0.

# Source prompts

Each file here is the **verbatim** prompt that drove the corresponding module. They are historical records, not documentation.

> **Naming note.** The product was renamed from **Ellie** to **Headsup** during Module 12. These prompts are deliberately **not** rewritten — they say "Ellie" because that is what was actually written and pasted at the time. Rewriting them would falsify the record.

Only the display name changed in the rename. `ELLIE_*` environment variables, `@ellie/*` package names, `ellie_*` MCP tool names and the OAuth `ellie_household` claim are unchanged, so every command and identifier quoted in these prompts still works.

`module-9.md` carries an additional caveat: it is a **reconstruction**, labelled as such in the file itself, because the original was never committed.
